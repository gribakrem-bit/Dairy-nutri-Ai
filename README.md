# 🥛 DairyNutri AI

AI-based nutritional and quality analysis of milk and dairy products.

## 📌 About the Project

DairyNutri AI is a machine-learning project that combines food science,
nutrition, dairy technology, and artificial intelligence.

The project aims to analyze nutritional and compositional data from
milk and dairy products and develop machine-learning models for
classification and prediction.

## 🎯 Objectives

- Analyze the nutritional composition of dairy products
- Explore relationships between milk and dairy components
- Classify dairy products using machine learning
- Develop predictive models based on compositional data
- Provide clear visualizations and analytical results
