# DairyNutri AI Dataset

## Source

The nutritional data used in DairyNutri AI are based on
USDA FoodData Central food-composition data.

Source:
https://fdc.nal.usda.gov/

## Variables

The dataset contains nutritional and compositional variables including:

- Energy (kcal)
- Fat (g)
- Protein (g)
- Carbohydrates (g)
- Calcium (mg)
- Sodium (mg)
- Water (g)

## Purpose

The dataset is used for exploratory nutritional analysis and
machine-learning experiments involving dairy products.

## Important Note

The current dataset is a prototype for demonstrating the
DairyNutri AI pipeline. Model performance should not be interpreted
as a validated scientific or commercial prediction system.
